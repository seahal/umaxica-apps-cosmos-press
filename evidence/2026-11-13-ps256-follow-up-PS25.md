## Changes

- Migrated first-party JWT signing and verification to PS256 with RSA keys of at least 3072 bits: OP
  ID/access/logout verification, OIDC client assertions and signed RP `state`, Jump return-token
  verification, JWK normalization/export/import, keyring signing, and private-key decoding.
- Private signing input now accepts only unencrypted RSA PKCS#8 PEM or base64-encoded PKCS#8 DER.
  Public JWKs must be RSA, PS256, signature-use, public-only, and at least 3072 bits. The selected
  JOSE header algorithm must match the key policy.
- Development/test key generation now creates RSA-3072 keys and PS256 kids. The local installer
  discards only complete generated legacy EC/ES384 entries from its local store and regenerates
  them. Existing local partial-environment repair behavior remains; issuer configuration is
  validated by the registry during boot.
- Press has an empty Jump RT issuer namespace and is a receiver only. The Edit RP signs its
  `private_key_jwt` assertion and `state` with its existing OIDC client key; no Jump issuer was
  added.
- Updated current ADRs, the Jump handoff checklist, JWT and Jump rotation runbooks, discovery
  profile notice, and DDS/SRS algorithm references. Historical decisions are identified as
  superseded without deleting their rationale.
- Updated tests for RSA/PS256 and RSA size boundaries. A pre-existing branch-coverage test that
  referenced the removed EC `CURVE` constant was updated to exercise RSA JWK validation instead.

The exact Press owner-provisioned key names are `OIDC_CLIENT_EDIT_ORG_WW_ACTIVE_KID`,
`OIDC_CLIENT_EDIT_ORG_WW_PRIVATE_KEY`, and `OIDC_CLIENT_EDIT_ORG_WW_PUBLIC_KEYSET`. The private key
value must be an unencrypted RSA-3072-or-larger PKCS#8 key. The owner must register the matching
public key with Access for the Edit client. KMS signing remains deferred; this work keeps the
existing environment/credential loading path.
