# Historical Acme, Sign, Core, Base and Palm Architecture

This file retains a pointer for plans and research that cite the former cross-surface Rails
architecture. Its implementation descriptions are retired and must not be used as the current route,
controller, host, or authority inventory.

As of the 2026-11-10 surface hard reset, this repository serves only Edit `org`, Docs, Help, Info
and News on `app`/`com`/`org`, and its operator tools. Auth, Base, Core, Palm, Tech, Visa and Warp
are not local Rails surfaces. Edit's external OIDC providers and Base preference/mail domain
dependencies remain external integrations.

Use [README.md](../../README.md) for the current surface inventory,
[controller boundaries](controller-boundaries.md) for controller ownership, and the
[subdomain reference](../reference/subdomains.md) for host ownership. Earlier architectural detail
below this boundary belongs to the historical ADRs and evidence that originally recorded it.
